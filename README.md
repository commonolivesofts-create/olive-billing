# Olivesoft Billing

Billing and Invoice Management System developed for Olivesoft
Software Pvt. Ltd.

## Project Overview

The application is developed using a shared frontend and backend
architecture within a single GitHub repository.

All modules and business requirements must follow the approved
project documentation.

## Technology Stack

- Frontend: React and Tailwind CSS
- Backend: Node.js and Express.js
- Database: MySQL
- Version Control: Git and GitHub
- Development Editor: Visual Studio Code

## Branching Strategy

- main: Stable application code.
- develop: Integrated development code.
- feature/backend-\*: Backend feature development.
- feature/frontend-\*: Frontend feature development.
- feature/integration-\*: Shared integration work.

## Development Rules

1. Maintain a single Git repository.
2. Work on separate feature branches.
3. Follow the approved business requirements.
4. Finalize API contracts before feature development.
5. Review and test code before merging.
6. Do not push incomplete features directly to main.
7. Never commit passwords, secrets or actual environment files.
8. Coordinate all shared configuration and API changes.
